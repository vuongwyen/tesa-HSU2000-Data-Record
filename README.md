# Tesa HSU2000 Data Record

## Overview
**Tesa HSU2000 Data Record** is a Windows Forms application designed to automate the process of capturing, processing, and syncing test data from an HSU2000 scale. It monitors a designated directory for incoming `.txt` output files generated by the HSU2000 hardware, parses the force values to calculate averages, and stores the results in a local SQLite database. Additionally, it seamlessly syncs the acquired data to a centralized remote server using RESTful APIs, with built-in mechanisms for connection retries during network outages.

## Features
- **Automated Data Capture:** Uses `FileSystemWatcher` to continuously monitor a specific folder for new `.txt` files generated by the HSU2000 scale.
- **Data Parsing Engine:** Reads and extracts force measurements (resolving decimal formats and invariant culture parsing) and computes the average force value automatically.
- **Local Persistence:** Employs Entity Framework Core (EF Core) with a local SQLite database to safely persist all test results.
- **Resilient Network Syncing:** Asynchronously queues data for network synchronization (`NetworkSyncService`). It uses JWT Bearer authentication to securely transmit data to a remote API. In case of network drops, it caches data locally and retries synchronization automatically.
- **Metadata Management:** Associates automated instrument data with operator-provided metadata such as Nart, Batch Code, Location, Sample Name, and Tester Name.
- **File Management:** Once a file is processed, it is automatically moved to a `Processed` subfolder to avoid duplicate processing.

## Technology Stack
- **Framework:** .NET 10.0 (Windows Forms)
- **Language:** C#
- **Database ORM:** Entity Framework Core (Microsoft.EntityFrameworkCore.Sqlite)
- **Data Export:** ClosedXML (For Excel functionalities)
- **UI Components:** DG.AdvancedDataGridView
- **Concurrency & Networking:** `HttpClient`, `ConcurrentQueue`, `Task` based async operations.

## Architecture & Core Services
- `HsuWatcherManager.cs`: Wraps the `FileSystemWatcher` logic to debounce events, ensure the file is completely written, parse it using the `HsuParserService`, and move the file into a `Processed` directory.
- `HsuParserService.cs`: Contains the core logic to stream the text file, replace comma-separated decimals, and extract force column data to compile the final `HsuTestResult`.
- `NetworkSyncService.cs`: A background service that runs a continuous loop processing a `ConcurrentQueue` of test results, performing JSON HTTP POST requests, and reporting sync status (Success, Error, Offline retries) back to the UI.
- `AppDbContext.cs`: Manages the SQLite database mappings and sets up the entity framework configurations for the data models.

## Requirements
- Windows OS
- .NET 10.0 Desktop Runtime

## Getting Started

1. Clone or download the repository.
2. Open the solution file `tesa HSU2000 Data Record.sln` (or `.slnx`) in Visual Studio 2022.
3. Build the solution to restore NuGet packages.
4. Run the application. 
5. Configure the monitor directory and the remote API endpoints through the application's configuration or UI.
6. The application will start monitoring the directory and syncing data as new `.txt` files appear.

# Ponytail Coding Ladder
Before writing any code, evaluate the problem through this strict ladder:
1. YAGNI: Does this code need to exist? If no, skip it.
2. Reuse: Is this already in the codebase? If yes, reuse it.
3. Stdlib/Platform: Can the standard library or native platform features (e.g., native HTML ``) do this? If yes, use it.
4. Dependency: Is there an installed package that does this? If yes, use it.
5. Write the absolute bare minimum that works. 
Never cut validation, error handling, security, or accessibility. Lazy about solution size, never negligent about safety.
